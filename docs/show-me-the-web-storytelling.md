# Show Me The Web Storytelling

## Problem

JS와 CSS의 동작 원리는 처음 배우는 사람에게 보이지 않는 일이다. 텍스트 설명만으로는 실행 순서와 화면 변화의 관계가 끊겨, 이해가 아니라 암기가 되어버린다.

## Approach

핵심 가설은 단순했다. 개념을 더 길게 설명하는 대신, 사용자가 실행 흐름을 눈으로 따라가고 직접 조작하게 만들면 추상적인 원리가 경험으로 바뀐다는 것. 그래서 콘텐츠의 중심을 강의식 설명이 아니라 시각적 인터랙션과 단계별 흐름으로 잡았다.

## Solution

JS 실행 과정은 타임라인 단위로 분해해 콜 스택과 이벤트 루프의 움직임을 순서대로 따라갈 수 있게 만들었다. CSS 역시 결과만 보여주는 대신 어떤 규칙이 어떻게 화면을 바꾸는지 흐름으로 연결했다. 설명, 조작, 결과가 한 화면 안에서 이어지도록 구성해 사용자가 개념을 읽는 것이 아니라 확인하고 납득하도록 만들었고, 교육 현장에서도 바로 활용할 수 있는 완성도를 기준으로 구조와 표현을 다듬었다.

## Takeaway

복잡한 개념을 단순하게 전달하는 일은 꾸미는 일이 아니라 본질을 정확히 이해해야 가능한 일이다. 이 프로젝트는 기술을 잘 쓰는 것만큼 잘 설명하는 것도 중요하다는 생각을 구현으로 검증한 경험이었다.
